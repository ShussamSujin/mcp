MCP가 뭐예요? 주소 모음 AI별 연결 방법 안전하게 쓰기

잠깐 쉬어 가세요.
연결은 AI가 할게요!!

복사하고 붙여넣느라 바빴던 손을 쉬게 해 주세요. 주소 한 줄이면 패들렛, 캔바, 노션이 내 AI에 이어져요. 이 연결 방법이 MCP예요.

주소 복사하러 가기 내 AI에 붙이는 방법

MCP가 뭐예요?

MCP는 AI와 앱을 이어 주는 약속이에요. 충전기를 USB-C 하나로 통일한 것처럼, AI와 앱을 잇는 구멍을 하나로 맞춘 거예요.

예전에는

패들렛 내용을 복사해서 AI에 붙여넣고, AI가 써 준 글을 다시 복사해서 캔바에 붙여넣었어요.

연결하면

AI가 패들렛을 직접 읽고, 캔바에 직접 만들어요. 선생님은 말로 부탁만 하면 돼요.

어떤 AI든 똑같이

같은 주소를 Gemini에도, Claude에도, ChatGPT에도 그대로 쓸 수 있어요. 그래서 주소만 알면 돼요!!

딱 3단계면 돼요

  1. 주소 복사

    아래 주소 모음에서 쓰고 싶은 앱의 복사 버튼을 눌러요.

  2. 내 AI에 붙여넣기

    AI의 설정에서 "연결된 앱"(커넥터) 메뉴를 열고, 복사한 주소를 붙여넣어요.

  3. 로그인하고 허용

    그 앱의 내 계정으로 로그인하면 연결 끝. 이제 말로 시켜 보세요.

MCP 서버 주소 모음

선생님들이 많이 쓰는 앱을 맨 위에 두었어요. 복사 버튼을 누르면 주소가 복사돼요.

로그인 내 계정으로 로그인만 하면 돼요 바로 사용 로그인 없이 써요 키 필요 그 서비스에서 받은 나만의 비밀 코드(키)가 있어야 해요 준비 필요 주소만으로는 안 되고 먼저 신청과 준비가 필요해요

주소는 2026년 11월 24일에 모았어요. "공식 안내에서 확인" 표시가 없는 주소는 인터넷에 공개된 목록에서 가져왔어요. 연결하기 전에 그 서비스의 공식 안내에서 한 번 더 확인해 주세요.

내 AI에는 어떻게 붙여요?

버튼 위치만 조금씩 달라요. 쓰는 AI를 골라 보세요.

  1. 컴퓨터에서 gemini.google.com에 들어가요.
  2. 설정 → 개인 인텔리전스 → 연결된 앱을 눌러요.
  3. 커넥터 탭에서 오른쪽 위 + 맞춤 버튼을 눌러요.
  4. 주소 칸(MCP 서버 URL)에 복사한 주소를 붙여넣고 다음을 눌러요.
  5. 안내에 따라 그 앱에 로그인하고 허용해요.
  6. 채팅에서 @를 입력하면 연결한 앱을 골라 쓸 수 있어요.

먼저 확인해요

  • 개인 구글 계정에서만 돼요. 학교·직장 계정은 아직 지원하지 않아요.
  • Gemini 활동 기록이 켜져 있어야 해요.
  • 연결은 컴퓨터에서 하고, 연결한 뒤에는 휴대전화에서도 쓸 수 있어요.
  • 구글 도움말은 미국·영어 기준으로 안내해요. 내 화면에 "맞춤" 버튼이 보이면 쓸 수 있어요.
  1. claude.ai에서 맞춤설정 → 커넥터로 들어가요.
  2. 추가 → 맞춤 커넥터 추가를 눌러요.
  3. 이름을 적고, 주소 칸(원격 MCP 서버 URL)에 복사한 주소를 붙여넣어요.
  4. 계속 → 추가를 누르고, 그 앱에 로그인해요.

먼저 확인해요

  • 무료 요금제도 맞춤 커넥터를 1개 쓸 수 있어요.
  • 패들렛, 캔바, 노션은 커넥터 목록에 이미 있어요. 주소 없이 "연결"만 눌러도 돼요.
  • 학교나 회사에서 단체로 쓰는 Claude는 관리자가 먼저 추가해 줘야 해요.
  1. 설정 → 앱으로 들어가요.
  2. 고급 설정에서 개발자 모드를 켜요.
  3. 앱 만들기를 누르고, 복사한 주소를 붙여넣어요.
  4. 로그인 방식을 고르고 만들기를 눌러요. 새 채팅에서 그 앱을 골라 써요.

먼저 확인해요

  • 요금제에 따라 달라요. "개발자 모드"가 안 보이면 지금 요금제로는 쓸 수 없어요.
  • 학교나 회사에서 단체로 쓰는 ChatGPT는 관리자가 먼저 켜 줘야 해요.
  • 패들렛, 캔바는 앱 목록에 이미 있어요. 주소 없이 연결할 수 있어요.
  1. 에이전트 패널 위쪽 … → MCP Servers를 눌러요.
  2. 목록에 있는 앱은 Install(설치)만 누르면 끝이에요.
  3. 목록에 없는 앱이면 Manage MCP Servers → View raw config를 눌러요. 설정 파일이 열려요.
  4. 열린 파일(mcp_config.json)에 "이대로 복사"로 복사한 글을 붙여넣고 저장해요.
  5. 설정 → 맞춤설정에서 새로고침하면 연결돼요.

안전하게 쓰기

    

    

      
    
        
  • 공식 주소만 연결해요. 주소의 도메인이 그 서비스의 진짜 도메인인지 확인해요. (예: padlet.com, canva.com)
    • 
        
  • 학생 개인정보는 넣지 않아요. 이름, 학번, 성적, 상담 내용이 담긴 자료는 연결한 AI에게 맡기지 않아요.
    • 
        
  • AI가 "실행할까요?"라고 물으면 내용을 읽고 눌러요. 글을 쓰거나 지우는 작업은 되돌리기 어려울 수 있어요.
    • 
        
  • 학교 계정은 관리자 정책을 따라요. 안 보이는 메뉴는 막혀 있는 거예요. 개인 계정으로 연습해 보세요.
    • 
        
  • 안 쓰는 연결은 꺼요. 연결된 앱 메뉴에서 언제든 연결 해제할 수 있어요.
